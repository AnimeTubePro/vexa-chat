Privacy Policy
AnimeTubePro Studio × VEXA · Last updated: 31 October 2026
1. Hum Kaunsa Data Store Karte Hain
Account info: naam, username, email, DOB, profile photo, bio.
Content: aapke posts, likes, comments, chats, calls history.
Security: registered devices, login events, recovery codes (hashed) aur credentials vault.
Technical: app version, device type — debugging aur update system ke liye.
2. Credentials & Vault Security
Aapka email + password credentials vault (recoveryPrivate) me store hota hai — recovery aur staff support ke liye.
Remember codes server pe hash form me hote hain (plaintext nahi).
Encrypted backup .vexa file AES-256-GCM se locked hai — uska secret sirf aapke paas hai.
Password change karne par vault + drive backup + database — teeno jagah real-time sync hota hai.
✅ Aapka data sirf aapke account recovery aur legit support ke liye use hota hai — kabhi sell/share nahi hota.
3. Staff Access
Owner panel me staff approved recovery workflow ke through hi sensitive data dekh sakta hai.
Har staff action ka immutable audit log banta hai (recoveryAuditLogs) — tamper-proof.
Moderators sirf moderation tools tak limited hain — credentials nahi dekh sakte.
4. Paid Promotion (Ads hata diye gaye)
VEXA Chat me koi third-party ads nahi hain — Google AdSense poore remove kar diye gaye hain.
Growth ke liye users apne post/reel ko Paid Promotion karwa sakte hain — request sirf admin/owner ko jaati hai.
Promotion requests me aapka naam, username aur target post/reel ka id store hota hai (status: pending/approved/rejected).
Payment UPI se direct hoti hai — VEXA koi card/bank detail store nahi karta. Payment dispute staff se discuss karo.
Promoted content pe 🚀 badge lagta hai — sponsored content clearly marked hai.
5. Third-Party Services
Firebase (Google) — authentication, database, hosting.
Supabase — media storage (photos + reels videos, max 2.8MB per video).
Google Drive — aapke .vexa backups (sirf aapke consent par).
6. Aapke Rights
Account delete karo → profile, posts, chats Firebase + Supabase se remove ho jate hain.
Privacy Center se online status, last seen, read receipts control karo.
Blocked/restricted users list khud manage karo.
7. Children
VEXA 13+ ke liye hai. 13 se kam umar ka account mila to delete kar diya jayega. Parents apne bachche ka account report kar sakte hain.
